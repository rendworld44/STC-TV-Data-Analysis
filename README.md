# STC TV Data Analysis 📊

A data analysis project based on the STC Jawwy TV dataset, focusing on user viewing behavior, program performance, watch duration, and HD usage.

## Project Overview

The project analyzes STC TV viewing data to understand user behavior and identify patterns in content consumption.

The analysis includes:
- Data cleaning and preparation
- Analysis of users and number of watches
- Total watch time analysis
- Identification of top programs
- Comparison between movies and series
- Analysis of user behavior based on HD quality
- Data visualization of key findings

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Jupyter Notebook

## Key Insights

The analysis identifies the most-watched programs based on total watch time, number of watches, and unique viewers. It also compares viewing behavior across program types and HD quality.
